# 文字节点发送到图片生成参考

## 目标

在自由画布文字节点的右键菜单中增加“发送到图片生成参考”。该动作把文字节点作为独立的文字参考加入图片生成草稿，而不是直接改写用户可见的 Prompt 输入框。

## 交互

- 右键菜单在“发送到 Agent”之后显示“发送到图片生成参考”。
- 点击后自动展开右侧面板并切换到“图片生成”。
- 图片生成器显示一个紧凑文字参考标签，标签文字使用文字节点名称，并提供移除按钮。
- 同一节点只能存在一个标签；再次发送同一节点会刷新其名称和正文快照，并保留原有排序位置。
- 空文字节点、预览模式或图片生成功能未启用时禁用该菜单项，并提供原因提示。
- 移除标签只影响图片生成草稿，不修改或删除画布文字节点。

## 数据模型

在 `ImageGenerationComposerDraft` 中增加有序的文字参考集合。每项保存：

- `nodeId`：去重和追踪来源。
- `label`：发送时的文字节点名称，用于标签展示。
- `text`：发送时的完整纯文本快照，用于最终 Prompt。
- `order`：多个文字参考的稳定顺序。

文字参考使用发送时快照。画布节点后续被改名、编辑或删除时，不会暗中改变已经加入图片生成草稿的内容；用户可以再次发送来刷新快照。

## Prompt 编译顺序

构建图片生成请求时，在前端把文字参考编译为普通文本段，不扩展后端 Prompt 协议：

1. 用户在图片生成输入框中的 Prompt 正文。
2. 按 `order` 排序后的文字参考正文。

各非空部分使用换行连接。图片引用段和图片输入继续按现有逻辑解析，不改变图片资产顺序、角色或 API 输入结构。

只有文字参考而没有用户正文时，仍视为有效 Prompt。提交后的请求快照保存已经编译的最终 Prompt，保证历史、重试和恢复继续使用现有通路。

## 边界与错误处理

- 空白文字参考不进入草稿。
- 重复节点不增加第二个标签。
- 移除不存在的文字参考保持草稿不变。
- 新建图片对话会清空文字参考；模型、分辨率等现有偏好保持原有行为。
- 不新增后端字段、存储表或运行时协议。

## 测试

- 右键菜单渲染新动作并发送正确命令。
- 空节点、预览模式和功能关闭时菜单项禁用。
- 文字参考添加、刷新去重、稳定排序和移除。
- 构建请求时用户正文位于所有文字参考正文之前。
- 只有文字参考时满足 Prompt 必填条件。
- 组件动作会切换并展开图片生成面板，显示节点名称标签。
- 完整前端测试、生产构建和真实浏览器交互复验。
